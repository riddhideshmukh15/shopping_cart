# Shopping Cart 🛒

A simple **Shopping Cart project in Python** made for beginners.

## Features

- Add items to the cart
- View cart items
- Exit the program
- Simple menu-based interface

## Concepts Used

- Lists
- `append()`
- `while` loop
- `for` loop
- `if/elif/else`
- User input

## How to Run

1. Make sure Python is installed.
2. Clone this repository.
3. Open the project folder in Terminal.
4. Run:

```bash
python shopping_cart.py
